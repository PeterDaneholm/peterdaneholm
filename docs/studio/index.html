The Approach

Understand first Production second

Daneholm Productions is an independent creative production studio working across moving image and still photography. The studio is intentionally flexible: each project starts with understanding your needs and getting us on the same page, before we start shooting anything.

Sport is the main area of interest, but also prioritize commercial projects, portraits, and documentary-inspired stories. The aim is to make visual work that feels considered, engaging and true to what it is about.

The studio works hands-on, emphasizing collaboration with clients and other creatives where a project calls for it. From an initial idea through production and delivery, the focus stays on the story and the details that make it distinct.
